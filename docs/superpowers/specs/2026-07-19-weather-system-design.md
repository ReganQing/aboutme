# 天气系统插件设计 · Ron567 个人主页

- 日期：2026-07-19
- 状态：已获用户批准（2026-07-19）
- 目标文件：`ron567-home/index.html`、新增 `ron567-home/weather.js`

## 1. 背景与目标

`ron567-home/index.html` 是单文件静态个人主页（深绿森林主题、玻璃拟态、1440px 固定画布按视口等比缩放）。需要增加一个**纯背景天气系统**：

- 内置三种天气：晴 / 雨 / 雪
- 用户可自由切换，切换控件放在 Headbar 右侧
- 不阻塞主页加载
- 仅作背景展示，不遮盖主内容区、不影响阅读

## 2. 已确认的产品决策

| 问题 | 决策 |
|---|---|
| 首次访问默认天气 | **默认关闭**（纯净阅读体验） |
| 控件形态 | **三图标分段控件**（玻璃胶囊，晴/雨/雪并排，当前项高亮） |
| 持久化 | `localStorage`，用户手动切换后记住选择，下次访问恢复 |
| 关闭方式 | 再点一次当前激活图标 → 回到「关」 |

## 3. 技术方案

Canvas 2D 粒子系统（对比过纯 CSS DOM 动画与 WebGL：前者随机感差、节点多；后者过度设计）。一块画布 + 单个 `requestAnimationFrame` 循环，三种渲染模式。

## 4. 层级与布局（不遮挡内容的关键）

- 画布为 `#stage` 的直接子元素：`position:absolute; inset:0; z-index:0; pointer-events:none;`
- 与现有雾光（`.fog`，z-index:0）同层，位于 `.content`（z-index:1）**之下**。
- 天气只透现在页面留白处与玻璃拟态半透明区域；页脚为不透明渐变背景，该区域不显示天气（可接受的视觉收尾）。
- 画布尺寸跟随 `#stage`（1440 × 实际内容高度），在现有 `fit()` 缩放后重算；DPR 上限 1.5 控制渲染开销。

## 5. 切换控件

- 位置：`.nav` 内、`.nav-cta`（联系我）左侧。
- 结构：`<div class="weather-switch" role="group" aria-label="天气切换">` 内三个 `<button>`，各含一个内联 SVG 图标（太阳 / 雨云 / 雪花），与现有 SVG 资产风格一致，不依赖 emoji 字体。
- 样式：玻璃胶囊（复用 `--glass`、`--glass-border`、`--green` 变量），激活项绿色高亮 + `aria-pressed="true"`。
- 按钮为静态 HTML（无布局偏移），JS 仅绑定事件。

## 6. 天气效果规格

| 天气 | 效果 | 粒子上限（按面积缩放） |
|---|---|---|
| 晴 `sun` | 暖色漂浮光斑/浮尘（林间光尘），极淡光线缓慢漂移 | ~70 |
| 雨 `rain` | 细斜雨丝下落，底部微小涟漪 | ~140 |
| 雪 `snow` | 雪花左右摇曳飘落，大小/透明度分层表现远近 | ~160 |

## 7. 性能与加载

- `weather.js` 独立文件，`<script defer>` 加载，不阻塞 HTML 解析。
- 天气为 `off` 时**不启动**任何动画循环；切换到某天天气时才创建粒子并启动 rAF。
- `document.visibilitychange`：标签页隐藏时暂停 rAF，可见时恢复。
- `prefers-reduced-motion: reduce`：不循环动画，仅在切换时绘制一帧静态画面。
- 粒子数量按画布面积缩放并设上限；单个 rAF 循环，无定时器。

## 8. 状态持久化

- 键：`localStorage["ron567-weather"]`，值 ∈ `off | sun | rain | snow`。
- 读取时机：defer 脚本执行时（DOM 解析完成后、load 前）；非法值回退为 `off`。
- 首次访问（无存储值）默认 `off`。
